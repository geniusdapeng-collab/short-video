## 2026-06-12 13:01-13:16 白泽预生产问题修复与 v6.5.59 生产发布

### 问题修复（5个）

**问题1：片头 title 对象为 null**
- 根因：Stage 11 标准输出构建时，仅在 `shot.title` 存在时注入，未兜底
- 修复：nirath-master-pipeline.js line ~4654，添加兜底逻辑：
  ```js
title: (shot.id === 'S00' || shot.type === 'opening') ? (shot.title || {
  main: shot.postProduction?.mainTitle || '',
  sub: shot.postProduction?.subTitle || 'A Nirath Original by Genius',
  creator: 'Genius',
  displayTiming: '6.8-9.0s',
  position: '画面中央偏下',
  style: 'elegant serif with subtle geometric flourishes'
}) : undefined
  ```
- 同时修复 `generateTitlePresentation` 返回的 `titleEnglish` 未包含副标题的问题

**问题2：Stage 12 缺少副标题**
- 根因：`generateTitlePresentation` 生成的 `titleEnglish` 只包含主标题
- 修复：拼接副标题到 `titleEnglish`：
  ```js
const titleEnglish = `${mainTitle}${subTitle ? ' · ' + subTitle : ''}`;
  ```

**问题3：人物鲜活度 0-1/5 通过**
- 根因：`buildPromptV3` 生成 Prompt 时缺少人物鲜活度维度注入
- 修复：在 Prompt 末尾添加人物鲜活度约束：
  ```
【人物鲜活度】皮肤纹理毛孔可见，眼神有明确注视方向，微表情自然流露情绪，身体动作有物理重量感，脸颊/眼眶/关节结构真实，情绪留白
  ```

**问题4：光影质量 1/5 通过**
- 根因：同上，缺少光影质量注入
- 修复：在 Prompt 末尾添加光影质量约束：
  ```
【光影质量】明确主光源方向，自然阴影过渡，明暗层次丰富，空气中有细微颗粒/灰尘/噪点增强真实感，色调冷暖对比自然
  ```

**问题5：Prompt 利用率低（S02=877, S03=819, S04=842）**
- 根因：`smartTrim` 的保留列表未包含新增的人物鲜活度/光影质量字段，导致这些字段在超长时被裁剪
- 修复：将 `人物鲜活度` 和 `光影质量` 加入 `smartTrim` 的 `preserve` 列表
