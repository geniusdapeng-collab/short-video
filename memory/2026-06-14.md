

### 视频需求清单确认流程问题修复（12:18-12:25）
**问题发现**：队长询问为什么没有输出《视频需求要点清单》让他确认

**根因分析**:
1. `systems/user-requirement-parser.js` 模块存在（Stage -1），功能完整
2. 但 pipeline 调用后**没有生成可视化的清单文档**返回给用户
3. pipeline 是**连续执行**的，没有中断点等待用户确认
4. 缺少"输出清单→等待确认→迭代→最终版"的完整流程

**已修复**:
1. **SOUL.md 焊死流程**：新增【视频需求清单确认流程】章节，明确6步流程
2. **AGENTS.md 记录流程**：在文件末尾添加完整的流程定义和字段要求
3. **关键要求**：预生产开始前必须先完成需求清单确认，未确认禁止启动

**流程定义**:
```
用户输入（一句话/简单描述）
 ↓
[解析] 提取所有明确信息 + [推断] 基于专业经验补全所有字段
 ↓
直接输出完整的《视频需求要点清单》
 ↓
请用户确认，或提出修改意见
 ↓
根据反馈迭代（最多1-2轮）
↓
输出最终版的《视频需求要点清单》给到下游
```

**清单必须包含字段**:
- 视频类型、时长、风格、平台、目标受众、角色、创意指数、结构规划、画幅比例

**违反后果** = 系统级错误，立即上报

**技术待修复**（下次迭代）:
- `user-requirement-parser.js` 需要增加生成 Markdown 清单文档的功能
- Pipeline 需要增加中断点，发送清单后等待用户反馈
- 需要实现 `iterate()` 方法的调用逻辑
