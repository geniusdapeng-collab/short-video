## 2026-06-10 02:07 ~ 02:55 - 超短裙系统 Prompt 扩充引擎 v0.7.1-xtreme-expanded

### 队长需求：将超短裙系统镜头 prompt 字符数从 ~85 扩充到 1500，提升短时间镜头信息密度和质感
- 仅超短裙系统生效，其他系统（Nirath主系统、超现实系统）完全不变
- 平台安全上限：1500 字符（要求不超过1000英文单词/500汉字，1500是中英文混合安全值）
- 最短不低于1200字符，目标1450字符（留50余量）

### 实现：Prompt 扩充引擎（集成到 `short-video-engine.js`）
- 动态扩充：运行时组合基础 prompt + 7维扩充，不硬编码到镜头库（控制文件大小）
- 7 维扩充维度：
  1. **视觉场景**（按运动类型动态匹配：雪山/万米高空/热带海洋/城市滑板公园/岩壁/泥土赛道/都市建筑）
  2. **运镜指令**（按视角动态匹配：POV/跟拍/侧拍/俯拍/仰拍，各视角专属运镜词库）
  3. **技术参数**（8K/120fps/Log/HDR/ProRes/8-11mm鱼眼/1000fps高速/FPV穿越机）
  4. **质感风格**（电影级/红牛/国家地理/IMAX/胶片质感/运动模糊/光晕）
  5. **环境音效**（风声/引擎/水花/雪粉/心跳/观众欢呼/碰撞声）
  6. **时间感知**（慢动作/时间凝固/关键帧/1/1000秒/时间膨胀/加速）
  7. **氛围情绪**（肾上腺素/突破极限/自由飞翔/征服恐惧/心流状态/生命力量）
- 强度>=9 时追加额外肾上腺素描述（15+关键词：生死一线/载入史册/品牌广告级）

### 核心函数
- `expandPrompt(basePrompt, sport, angle, intensity)` — 7维动态扩充，返回目标1450字符
- `truncateToLength(str, maxLength)` — 智能截断，优先保留完整句子（句号/逗号/空格处截断）
- `checkPromptLength(prompt)` — 返回 { length, status, ratio }，status: ok/overflow/under
- `qualityCheck(prompt)` — 质量门检查，检测溢出、包含关键词、是否中文
- `autoCompletePrompt(prompt)` — 自动补全，若不足1200字符补充至目标

### 生成流程集成
- `generateXtremeShort()` 和 `generateSingleAngleShort()` 默认启用 `expand: true`
- 可选关闭：`expand: false` 保持原始基础prompt（兼容旧版）
- 每个镜头在生成时自动扩充，输出含 `expandedPrompt` 和 `promptCheck`（字符数报告）
