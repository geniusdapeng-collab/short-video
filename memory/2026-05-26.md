## 2026-05-26 22:45 神兽出场Agent v2.0重构 — 从模板到灵气

### 队长核心洞察
"你之前给的是 5 种固定模式，这个套模板的…一点灵气都没有。每个出场都是独一无二的…这才是我们需要的"

### 新设计哲学：零模板、全灵气
1. **身体部位即出场语言** — 腋下之眼→先在黑暗中睁开照亮周围；九尾→尾巴先在雾中若隐若现
2. **能力即出场节奏** — 烛龙睁眼为昼→画面亮度瞬间拉满；饕餮吞噬→物质向中心塌缩
3. **移动方式绑定登场空间** — 会飞→天空/云层；会遁地→地底/岩浆；有幻术→现实裂缝

### 架构重构
```
BeastFeatureAnalyzer → 深度分析异兽档案
  ├── extractBodyParts() — 从bodyPlan提取所有身体部位
  ├── inferMovementType() — 推断移动方式（飞/遁/游/行）
  ├── extractVisualElements() — 颜色/纹理/特效
  └── generateKeyTraits() — 生成关键特征摘要

EntranceDesigner → 基于特征动态设计
  ├── designPrecursor() — 基于最关键特征制造悬念
  ├── designBurst() — 全屏铺满，核心特征集中展现
  ├── designAftermath() — 环境反应留下印象
  ├── composeFullScreen() — 最具视觉冲击的特征铺满画面
  └── composeAudio() — 基于移动方式+能力生成音效
```
