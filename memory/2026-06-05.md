## Prompt 1000字符合规修复（v6.3-patch4，11:07-11:57）

### 队长发现的问题
- 队长指出：Prompt 1306/1415字符，超过 Seedance API 1000字符底线
- 质问："怎么合规的？"

### 根因分析
1. 系统模板太长：476字符（环境质感、全局负面约束、技术规格等冗长描述）
2. 创意部分要求太高：Stage 3a要求800-1200字符
3. 两者相加：476 + 830 = 1306字符，超标30%

### 修复方案
- **系统模板精简**：476→256字符（删除冗余描述，保留核心约束：ASTRALIS、环境质感、负面约束、明亮约束、风格锁、角色约束、技术规格）
- **创意部分下调**：800-1200→500-650字符
- **质量门同步适配**：`_checkStructure` 从检查旧字段名改为检查新精简字段名（【视觉】【镜头时间轴】【环境音效】）

### 修复过程
- 11:43 - 模板精简后测试：796/831字符，但结构检查失败（字段名未适配）
- 11:57 - 结构检查适配后：100分通过，796/831字符，全部合规！

### 验证结果
- **S00**: 796字符，100分 ✅
- **S01**: 831字符，100分 ✅
- 质量门8项：全部通过 ✅
- 耗时：8.5分钟（比26分钟大幅缩短）

### 经验总结
1. **1000字符是硬性底线**：任何情况下都不能超过，必须严守
2. **系统模板可以精简**：不影响核心信息传达，冗余描述可删除
3. **质量门必须与模板同步**：修改模板后，检查逻辑必须同步适配
4. **Prompt 越短越好**：在1000以内留有余量，避免边缘情况触发超限
