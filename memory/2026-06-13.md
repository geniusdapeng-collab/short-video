
## 2026-06-13 - 角色多风格定妆照管理系统设计

### 背景
队长要求："一个人会有多种不同风格的定妆照，要做好管理，根据制作内容的需要进行调用。不同镜头展示不同场景时，调用不同的定妆照。"

### 系统设计

#### 1. 注册表架构 (`character-portrait-registry.json`)
```json
{
  "characters": {
    "chen-nurse": {
      "styles": {
        "police": { ... },
        "life-summer": { ... }
      }
    }
  },
  "selectionRules": {
    "sceneToStyleMapping": {
      "警局": "police",
      "家庭": "life-summer"
    }
  }
}
```

#### 2. 选择器逻辑 (`portrait-selector.js`)
- **输入**: 角色ID + 场景描述 + 角度
- **输出**: 定妆照绝对路径
- **选择策略**:
  1. 精确场景匹配 → 风格
  2. 模糊关键词匹配 → 风格
  3. 默认风格兜底
  4. 角度选择: front/closeup/fullBody/sitting/walking/etc.

#### 3. 流水线集成方案
**每个镜头生成时**:
```javascript
const selector = new PortraitSelector();

// 对于镜头中出现的每个角色
for (const character of shot.characters) {
  const portraitPath = selector.selectPortrait(
    character.id,
    shot.scene,      // "警局" / "客厅" / "公园"
    shot.cameraAngle // "front" / "closeup" / "fullBody"
  );
  
  // 注入到角色引用中
  character.portraitRef = `image://${portraitPath}`;
}
```

#### 4. 当前陈卓定妆照库存

**警服风格 (police)** - 5张:
- front / threeQuarter / side / closeup / fullBody
- 适用场景: 警局、执法、办公室-正式

**生活-夏天风格 (life-summer)** - 8张:
- front / threeQuarter / side / closeup / fullBody / sitting / walking / holdingBaby
- 适用场景: 家庭、客厅、卧室、阳台、公园
