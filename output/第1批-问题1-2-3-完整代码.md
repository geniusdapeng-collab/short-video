## 问题1：需求确认流程未正确中断

### 现象
- Stage -1 返回 `REQUIREMENT_CONFIRMATION_REQUIRED`，但系统继续往下执行 Stage 0+
- 用户输入任务后，没有先停在需求清单确认，而是直接进入预生产链路

### 期望
- 输出需求清单后，**等待用户回复"确认"**再继续
- 未确认前，不进入主链路

### 根因分析
`execute` 方法中 Stage -1 返回 `REQUIREMENT_CONFIRMATION_REQUIRED` 后，外层调用者（如 `run-health-edu-ep01.js`）没有检查该状态，直接继续执行。同时，`execute` 方法内部虽然返回了该状态，但调用者没有处理。

---

## 问题2：LLM content 为空 + JSON 解析失败

### 现象
- `debug_llm/` 中大量 `empty_content_reasoning` 和 `json_extract_fail_content` 日志
- `llm-reasoning-engine.js` 中 `reason` 方法返回 `content` 为空时，从 `reasoning_content` 兜底提取
- 提取的 reasoning 内容不是合法 JSON，导致后续 `JSON.parse` 失败

### 期望
- 强制 LLM 输出合法 JSON 到 `content` 字段
- `reasoning_content` 不应作为 JSON 数据的来源
- 增加 `response_format: { type: 'json_object' }` 约束

### 根因分析
`llm-reasoning-engine.js` 中 `reason` 方法：
1. 调用 API 时未强制 `response_format: { type: 'json_object' }`（仅在 `reasonStructured` 中设置）
2. `content` 为空时，从 `reasoning_content` 提取文本，但提取逻辑依赖关键词匹配（如 'Nirath'、'小G'），对科普/通用内容无效
3. `normalizeLLMOutput` 处理后的 `text` 为空时，fallback 到 reasoning 内容，但 reasoning 内容往往不是合法 JSON

---

## 问题3：主进程无子进程模式，但系统疑似使用子进程

### 现象
- `execute` 方法中 Stage 11~17 使用 `child_process.spawn` 启动 PromptForge Director 子进程
- 子进程内存限制 `--max-old-space-size=8192`
- 系统总内存约 7.5GB，子进程可能触发 OOM SIGKILL
- `_releaseMemory` 方法在 v6.5.59 中被注释掉

### 期望
- 明确是否使用子进程模式
- 若内存不足，子进程应被优雅处理，不应导致主链路崩溃
- 恢复 `_releaseMemory` 调用或修复内存释放逻辑

### 根因分析
1. `zhuoyue-system/core/nirath-master-pipeline.js` line 901+ 使用 `spawn` 启动子进程
2. 子进程超时 1800秒，内存限制 8192MB
3. `_releaseMemory` 被注释（line 816），内存无法释放

      '5. 输出必须能被 JSON.parse 直接解析',
      '',
      '【目标JSON结构示例】',
      JSON.stringify(schema, null, 2)
    ].join('\n');

    let lastError = null;

    for (let attempt = 1; attempt <= this.maxRetries; attempt++) {
      const result = await this.reason(structuredPrompt, {
        ...options,
        responseFormat: { type: 'json_object' },
        temperature: options.temperature ?? 0.1,
        maxTokens: options.maxTokens ?? this.maxTokens
      });

      if (!result.success) {
        lastError = result.error;
        console.warn(`[LLMEngine] ⚠️ reasonStructured attempt ${attempt}/${this.maxRetries} 失败: ${lastError}`);
        continue;
      }

      try {
        const extracted = this._extractJsonObject(result.content);
        if (!extracted) {
          const dump = this._dumpDebugFile('json_extract_fail_content', result.content);
          throw new Error(`无法从content提取合法JSON${dump ? ` | dump=${dump}` : ''}`);
        }

        const parsed = JSON.parse(extracted);

        return {
          success: true,
          data: parsed,
          rawContent: result.content,
          reasoning_content: result.reasoning_content
        };
      } catch (parseError) {
        lastError = `JSON parse error: ${parseError.message}`;
        console.warn(`[LLMEngine] ⚠️ reasonStructured attempt ${attempt}/${this.maxRetries} 解析失败: ${lastError}`);
      }
    }

    return {
      success: false,
      error: lastError || '未知错误'
    };
  }
}

module.exports = { LLMEngine };
