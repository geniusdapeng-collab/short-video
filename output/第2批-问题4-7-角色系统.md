## 调用链

```
入口脚本 run-health-edu-ep01.js
  -> 定义 characters['chen-nurse'].visual.outfit = 'standard Chinese police uniform...'
  -> NirathMasterPipeline::execute(input)
     -> Stage 4: stageCharacters(input, prd)
        -> CharacterManagerV2::buildRenderPrompt('chen-nurse')
           -> CharacterPromptBuilder::build(character, options)
              -> 从 character.visualIdentity 提取服装信息
                 -> 无 outfit 字段 -> fallback 到 role 推断
                    -> role='nurse' -> _getDefaultClothing() 返回 '白色护士服'
                       -> 生成错误服装（白色护士服 vs 警服）
```

## 问题4：角色服装推断错误

### 现象
- 入口脚本定义陈卓角色 `outfit: 'standard Chinese police uniform with formal police cap'`
- 但生成的镜头Prompt中，角色服装被错误推断为 `白色护士服`
- `character-prompt-builder.js` 中 `_getDefaultClothing()` 根据 `role='nurse'` 推断服装，忽略入口脚本定义的 `outfit`

### 期望
- 入口脚本定义的 `outfit` 应被正确传递到角色提示词中
- 警服描述应出现在最终Prompt中

### 根因分析
1. **入口脚本 vs 角色档案分离**：
   - 入口脚本 `run-health-edu-ep01.js` 在 `characters['chen-nurse'].visual.outfit` 中定义了警服
   - 但 `CharacterManagerV2` 从 `characters/chen-nurse/character-card.json` 加载角色档案
   - 角色档案中 **无 `outfit` 字段**，且 `role` 是 `nurse`

2. **服装推断逻辑缺陷**：
   - `character-prompt-builder.js` 中 `clothing` 层构建逻辑：
     - 优先从 `vi.appearance.clothing.promptFragment` 提取
     - 若无，则调用 `_getDefaultClothing(role, gender, age, name)`
     - `_getDefaultClothing` 根据 `role='nurse'` 返回 `白色护士服`
   - **从未检查入口脚本传入的 `visual.outfit` 字段**

3. **数据同步缺失**：
   - 入口脚本定义的角色数据与磁盘上的角色档案不同步
   - 系统未将入口脚本的 `outfit` 定义合并到角色档案中

## 问题7：角色档案缺乏outfit字段

### 现象
- `characters/chen-nurse/character-card.json` 中无 `outfit` 字段
- `visualIdentity` 中只有基础信息（age/gender/build等），无服装描述
- `v2Metadata.minimalAnchor` 包含 "Nirath异兽, Nirath原生特征, 双恒星光照反射"（山海经残留）

### 期望
- 角色档案应包含准确的服装描述（警服）
- generic模式角色不应包含Nirath相关描述
- 入口脚本定义的 `outfit` 应自动同步到角色档案

### 根因分析
1. **角色档案创建时未包含outfit**：
   - `character-manager-v2.js` 的 `createCharacter()` 方法未从 `characterData` 中提取 `outfit`
   - 角色档案的 `visualIdentity` 结构缺乏服装专用字段

2. **Nirath残留**：
   - `character-card.json` 中 `v2Metadata.minimalAnchor` = "陈卓: Nirath异兽, Nirath原生特征, 双恒星光照反射"
   - `_buildMinimalAnchor()` 方法默认 `race = 'Nirath异兽'`，未根据实际角色类型调整

    const isChild = age !== null && age < 14;

    if (name && (name.includes('小') || name.includes('G'))) {
      if (isChild) return '休闲运动童装';

    if (name && name.includes('护士')) return '白色护士服';
    if (name && name.includes('教练')) return '专业运动教练服';

    if (isChild) {
      if (gender === 'male' || gender === 'boy') return '休闲运动童装';
      if (gender === 'female' || gender === 'girl') return '可爱连衣裙';
      return '童装';
    }

    const clothingMap = {
      'nurse': '白色护士服',      // ← BUG: 陈卓 role='nurse' 但应穿警服
      'doctor': '白大褂',
      'coach': '专业运动教练服',
      'host': '正装',
      'expert': '商务休闲装',
      'patient': '病号服',
      'teacher': '衬衫西裤',
      'student': isChild ? '童装' : '校服',
      'audience': '便装'
    };

    return clothingMap[lowerRole] || (
      gender === 'female' ? '职业套装' :
      gender === 'male' ? '衬衫' : '便装'
    );
  }

  build(character, options = {}) {
    const {
      angle = 'threeQuarter',
      sceneType = 'interaction',
      expression,
      environment,
      enabledLayers = Object.keys(this.LAYER_TEMPLATES),
      layerWeights = {},
      maxChars = this.config.maxChineseChars
    } = options;
    
    const weights = { ...this.config.defaultLayerWeights, ...layerWeights };
    
    const orderedLayers = this.config.priorityOrder
      .filter(l => enabledLayers.includes(l))
      .map(layerId => ({
        id: layerId,
        ...this.LAYER_TEMPLATES[layerId],
        weight: weights[layerId] || 1.0
      }));
    
    const layers = {};
    for (const layer of orderedLayers) {
      const content = layer.build(character, angle, sceneType, 
        layer.id === 'expression' ? expression : 
        layer.id === 'environment' ? environment : undefined);
      
      if (content && content.trim()) {
        layers[layer.id] = {
          name: layer.name,
          content,
          weight: layer.weight,
          charCount: this._countChineseChars(content)
        };
      }
    }
    
    const finalLayers = this._allocateSpace(layers, maxChars);
    
    const promptParts = orderedLayers
      .filter(l => finalLayers[l.id] && finalLayers[l.id].included)
      .map(l => finalLayers[l.id].content);
    
    const prompt = promptParts.join('，');
    
    return {
      prompt,
      layers: finalLayers,
      stats: {
        totalChars: this._countChineseChars(prompt),
        maxChars,
        utilization: (this._countChineseChars(prompt) / maxChars * 100).toFixed(1) + '%',
        layerCount: Object.values(finalLayers).filter(l => l.included).length,
        layerDetails: finalLayers
      },
      negativePrompt: this._buildNegativePrompt(character)
    };
  }
  
  _buildNegativePrompt(character) {
    const defaults = [
      'western face', 'caucasian', 'european', 'american',
      'blonde hair', 'blue eyes', 'red eyes', 'green eyes',
      'cartoon style', 'anime style', '3D render',
      'plastic skin', 'doll-like'
    ];
    return [...new Set(defaults)].join(', ');
  }
  
  _allocateSpace(layers, maxChars) {
    const result = {};
    let remaining = maxChars;
    
    for (const [id, layer] of Object.entries(layers)) {
      result[id] = { ...layer, included: true, trimmed: false };
    }
    
    const totalNeeded = Object.values(result)
      .filter(l => l.included)
      .reduce((sum, l) => sum + l.charCount, 0);
    
    if (totalNeeded <= maxChars) {
      return result;
    }
    
    const sortedByWeight = Object.entries(result)
      .filter(([_, l]) => l.included)
      .sort((a, b) => a[1].weight - b[1].weight);
    
    for (const [id, layer] of sortedByWeight) {
      if (remaining <= 0) {
        result[id].included = false;
        continue;
      }
      
      const weightRatio = layer.weight / 
        sortedByWeight.filter(([_, l]) => l.included).reduce((s, [_, l]) => s + l.weight, 0);
      
      const allocated = Math.floor(maxChars * weightRatio);
      
      if (layer.charCount > allocated) {
        result[id].content = this._trimToLength(layer.content, allocated);
        result[id].trimmed = true;
        result[id].originalCharCount = layer.charCount;
        result[id].charCount = this._countChineseChars(result[id].content);
      }
      
      remaining -= result[id].charCount;
    }
    
    return result;
  }
  
  _trimToLength(text, maxLen) {
    if (this._countChineseChars(text) <= maxLen) return text;
    let trimmed = text.substring(0, maxLen);
    const lastPunct = Math.max(
      trimmed.lastIndexOf('，'),
      trimmed.lastIndexOf('。'),
      trimmed.lastIndexOf('、')
    );
    if (lastPunct > maxLen * 0.7) {
      trimmed = trimmed.substring(0, lastPunct + 1);
    }
    return trimmed;
  }
  
  _countChineseChars(text) {
    if (!text) return 0;
    const chineseChars = (text.match(/[\u4e00-\u9fa5]/g) || []).length;
    const englishWords = (text.match(/[a-zA-Z]+/g) || []).length;
    return chineseChars + englishWords * 2;
  }
}

module.exports = { CharacterPromptBuilder };

 * 【角色管理系统 v2】Character Manager v2.0

const fs = require('fs').promises;
const fss = require('fs');
const path = require('path');
const { CharacterComplianceChecker } = require('./character-compliance-checker.js');
const { CharacterPromptBuilder } = require('./character-prompt-builder.js');
const { CharacterEraGuide } = require('./character-era-guide.js');
const { GrowthTraceSystem } = require('./growth-trace-system.js');

  constructor(config = {}) {

      autoCheckCompliance: config.autoCheckCompliance ?? true,
      maxChineseChars: config.maxChineseChars ?? 1500,

    };

  }
  
  ensureDirectory() {
    if (!fss.existsSync(CHARACTERS_DIR)) {
      fss.mkdirSync(CHARACTERS_DIR, { recursive: true });
    }
  }
  
  getCharacterDir(characterId) {
    return path.join(CHARACTERS_DIR, characterId);
  }
  
  getCharacterCardPath(characterId) {
    return path.join(this.getCharacterDir(characterId), 'character-card.json');
  }
  
  characterExists(characterId) {
    return fss.existsSync(this.getCharacterCardPath(characterId));
  }
  
  async loadCharacter(characterId) {
    const cardPath = this.getCharacterCardPath(characterId);
    try {
      const data = await fs.promises.readFile(cardPath, 'utf8');
      return JSON.parse(data);
    } catch {
      return null;
    }
  }
  
  async saveCharacter(characterId, characterCard) {
    characterCard.updatedAt = new Date().toISOString();
    characterCard.version = characterCard.version || '2.0';
    const cardPath = this.getCharacterCardPath(characterId);
    await fs.writeFile(cardPath, JSON.stringify(characterCard, null, 2));
  }
  
  createCharacter(characterId, characterData) {
    const characterDir = this.getCharacterDir(characterId);
    if (!fss.existsSync(characterDir)) {
      fss.mkdirSync(characterDir, { recursive: true });
    }
    
    // v6.5.62-P1: 生成极简锚点
    const minimalAnchor = this._buildMinimalAnchor(characterData);
    
    // v6.5.62-P1: 生成定妆照路径
    const portraitPaths = this._buildPortraitPaths(characterId, characterData);
    
    const characterCard = {
      ...characterData,
      id: characterId,
      createdAt: new Date().toISOString(),
      updatedAt: new Date().toISOString(),
      version: '2.0',
      generatedAssets: {
        portraits: portraitPaths,
        referenceImages: []
      },
      appearances: [],
      v2Metadata: {
        analyzedDimensions: [],
        lastComplianceCheck: null,
        promptTemplates: {},
        minimalAnchor: minimalAnchor,
        portraitPaths: portraitPaths
      }
    };
    
    this.saveCharacter(characterId, characterCard);
    return characterCard;
  }

  /**
   * v6.5.62-P1: 构建极简锚点（character字段）
   * BUG: 默认 race='Nirath异兽'，未根据实际角色类型调整
   */
  _buildMinimalAnchor(characterData) {
    const charName = characterData.name || characterData.id || '未知角色';
    const race = characterData.race || characterData.species || 'Nirath异兽'; // ← BUG: 默认Nirath
    
    const keywords = [];
    if (characterData.signatureFeatures) {
      keywords.push(...characterData.signatureFeatures.slice(0, 3));
    }
    if (characterData.coreVisualTraits) {
      keywords.push(...characterData.coreVisualTraits.slice(0, 2));
    }
    if (characterData.appearance) {
      const appearanceKeywords = characterData.appearance.split(/[,，]/)
        .map(s => s.trim())
        .filter(s => s.length > 0);
      keywords.push(...appearanceKeywords.slice(0, 2));
    }
    
    const uniqueKeywords = [...new Set(keywords)].slice(0, 5);
    if (uniqueKeywords.length < 3) {
      uniqueKeywords.push('Nirath原生特征', '双恒星光照反射'); // ← BUG: 硬编码Nirath
    }
    
    return `${charName}: ${race}, ${uniqueKeywords.join(', ')}`;
  }
  
  /**
   * v6.5.62-P1: 构建定妆照路径
   */
  _buildPortraitPaths(characterId, characterData) {
    const paths = [];
    const angles = ['front', 'threeQuarter', 'closeup', 'side', 'back', 'action', 'detail'];
    
    for (const angle of angles) {
      paths.push(`image://bestiary/${characterId}-${angle}.png`);
    }
    
    return paths.slice(0, 9);
  }
  
  // ... 其他方法省略（7维分析、合规检查、Prompt构建等）
}

module.exports = { CharacterManagerV2 };
