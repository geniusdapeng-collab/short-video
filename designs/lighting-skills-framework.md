# 光影技能体系设计框架

## 目标
打造好莱坞导演级的光影精品技能，支持软性注入和外挂调用。

## 技能分类（3-5个深度精品）

### 1. 三点照明大师 (Three-Point-Lighting-Master)
**定位**: 基础照明技能，所有场景必备
**核心能力**:
- Key Light（主光）: 位置、色温、强度、方向
- Fill Light（补光）: 柔化阴影、填充暗部
- Rim Light（轮廓光）: 人物分离、边缘勾勒
- 光比控制: 高调/低调/正常对比度

**输出格式**:
```
【照明方案】三点照明：主光从[方向]以[色温]K [强度]照射，辅光从[方向]柔和填充，轮廓光从后方勾勒边缘，光比[比例]，营造[氛围]。
```

### 2. 情绪光影导演 (Emotional-Lighting-Director)
**定位**: 根据情绪自动匹配光影方案
**核心能力**:
- 焦虑/紧张: 高对比度、硬边阴影、冷色调
- 温暖/舒适: 柔和漫射、暖色调、低对比
- 神秘/悬疑: 侧光、局部照明、明暗对比
- 希望/明亮: 高调照明、均匀布光、暖色温

**输出格式**:
```
【情绪光影】[情绪类型]氛围：主光[方案]，阴影[特征]，色彩[倾向]，整体[效果]。
```

### 3. 环境光效设计师 (Environmental-Lighting-Designer)
**定位**: 根据场景类型设计环境光效
**核心能力**:
- 室内日光: 窗户光、漫射、自然色温
- 夜景/人工: 灯光色温混合、点光源、反射
- 户外自然: 天空光、直射阳光、阴影方向
- 特殊场景: 医院冷白、餐厅暖黄、舞台戏剧性

**输出格式**:
```
【环境光效】[场景类型]照明：[主光源]从[位置]进入，[辅助光源]提供[效果]，整体[色温]K，[对比度描述]。
```

### 4. 动态光影编排师 (Dynamic-Lighting-Choreographer)
**定位**: 镜头内的光影变化和运动
**核心能力**:
- 时间过渡: 晨→午→暮→夜的光影变化
- 情绪递进: 从明亮到昏暗的叙事推进
- 运动配合: 跟焦时的光影跟随、推拉时的明暗变化
- 特效光: 闪电、烛光闪烁、霓虹脉冲

**输出格式**:
```
【动态光影】时间轴：起点[光影状态]→过渡[变化方式]→终点[光影状态]，配合[运镜动作]。
```

### 5. AI视频真实感光影专家 (AI-Realism-Lighting-Expert)
**定位**: 针对AI视频生成的光影优化（结合v6.6.1真实感系统）
**核心能力**:
- 物理正确性: 光源位置与阴影方向一致
- 材质响应: 金属反光、皮肤次表面散射、布料漫反射
- 大气效果: 雾气散射、体积光、镜头眩光
- 胶片质感: 柯达/富士色彩、颗粒感、暗角

**输出格式**:
```
【AI光影】物理照明：[光源类型]产生[阴影特征]，[材质]呈现[反射特性]，大气[效果]，胶片[风格]。
```

## 调用方式

### 方式1: 软性注入（Prompt增强）
在Stage 11渲染核心中，根据场景类型和情绪自动注入光影描述。

### 方式2: 外挂技能（Skill调用）
作为独立技能文件，根据导演决策显式调用。

### 方式3: 混合模式
基础光影自动注入 + 特殊场景技能增强。

## 与现有系统集成

```
Stage 11 (渲染核心)
  ├── 现有: 运镜系统 (AstralisCameraEngine)
  ├── 现有: 情绪增强
  ├── 新增: 光影技能注入 ← 在这里接入
  └── 输出: 完整Prompt
```
