# 创意指数系统 (Creative Intensity Index) v2.0-Peng

## 核心概念

**创意指数（Creative Intensity Index, CII）= 影视呈现手法的强度**

- 只影响"怎么拍"（外在影视表现层），不影响"拍什么"（内容/事实层）
- 默认 **0.2**（用户不填 = 系统自主，不干预技能调用和创意程度）
- 数值越高：调用技能维度越多 + 每个技能的创意程度越深

---

## 用户输入解析器（第一层）

### 直接数值映射
```
0.2 = 系统默认（不干预）
0.3-0.4 = 轻度干预
0.5-0.6 = 中度干预
0.7-0.8 = 深度干预
0.9-1.0 = 极致干预
```

### 解析逻辑
```javascript
function parseCreativeIntensity(userInput) {
  // 1. 提取用户输入中的关键词
  // 2. 尝试匹配数值（如"0.7"、"0.5"）
  // 3. 尝试匹配语义词（如"非常有创意"）
  // 4. 如果什么都没匹配到，返回默认 0.2
  // 5. 返回 { value: 0.7, source: '语义匹配', keyword: '非常有创意' }
}
```

## 模块激活算法

```javascript
// 每个模块的激活阈值（指数 ≥ 阈值时激活）
const MODULE_REGISTRY = {
  camera:      { threshold: 0.35, stage: ['STAGE-9'],             weight: 0.15 },
  lighting:    { threshold: 0.30, stage: ['STAGE-10', 'STAGE-11'], weight: 0.12 },
  production:  { threshold: 0.40, stage: ['STAGE-5B', 'STAGE-10'], weight: 0.10 },
  editing:     { threshold: 0.45, stage: ['STAGE-6', 'STAGE-7'],   weight: 0.08 },
  sound:       { threshold: 0.35, stage: ['STAGE-12'],             weight: 0.08 },
  color:       { threshold: 0.30, stage: ['STAGE-10', 'STAGE-11'], weight: 0.10 },
  composition: { threshold: 0.35, stage: ['STAGE-9', 'STAGE-10'],  weight: 0.08 },
  performance: { threshold: 0.40, stage: ['STAGE-5B'],             weight: 0.07 },
  vfx:         { threshold: 0.50, stage: ['STAGE-11'],             weight: 0.05 },
  cinematic:   { threshold: 0.45, stage: ['STAGE-9'],             weight: 0.06 },
  atmosphere:  { threshold: 0.35, stage: ['STAGE-10'],             weight: 0.07 },
  texture:     { threshold: 0.55, stage: ['STAGE-11'],             weight: 0.04 },
  time:        { threshold: 0.50, stage: ['STAGE-6', 'STAGE-9'],   weight: 0.05 },
  space:       { threshold: 0.45, stage: ['STAGE-10'],             weight: 0.06 }
};

function getActiveModules(intensity) {
  return Object.entries(MODULE_REGISTRY)
    .filter(([id, config]) => intensity >= config.threshold)
    .map(([id, config]) => ({ id, ...config }));
}
```

## 链路注入器（Stage映射）

```javascript
// 每个 Stage 接收哪些模块指令
const STAGE_INJECTION_MAP = {
  'STAGE-5B': ['performance', 'production'],
  'STAGE-6':  ['editing', 'time'],
  'STAGE-7':  ['editing'],
  'STAGE-9':  ['camera', 'composition', 'cinematic', 'time'],
  'STAGE-10': ['lighting', 'color', 'atmosphere', 'space', 'production'],
  'STAGE-11': ['lighting', 'color', 'vfx', 'texture', 'atmosphere'],
  'STAGE-12': ['sound']
};

function generateStageInstructions(stageName, intensity) {
  const activeModules = getActiveModules(intensity);
  const stageModules = STAGE_INJECTION_MAP[stageName] || [];
  
  const injections = activeModules.filter(m => stageModules.includes(m.id));
  
  return injections.map(m => {
    const level = getLevel(intensity);
    return `[${m.id.toUpperCase()}:${level}] ${getInstruction(m.id, level)}`;
  }).join('\n');
}
```

## 主链路注入点

```
用户输入
  ↓
STAGE-0: 创意指数解析（新增）
  ├─ 提取关键词/数值
  ├─ 翻译为 0.0-1.0 数值
  └─ 输出: creativeIntensity = 0.7
  
STAGE-1: PRD生成
  ↓ 根据指数调整视觉风格方向（如指数0.9→PRD中增加"电影级视觉"要求）
  
STAGE-2: 需求对齐
  ↓ 确认指数与内容类型兼容性（内容防火墙检查）
  
STAGE-3: Schema构建
  ↓ 在 schema 中注入 creativeIntensity 字段
  
STAGE-5: 剧本/视觉生成
  ↓ 根据指数决定激活哪些模块
  ↓ 注入表演、布景模块指令
  
STAGE-6: 时长分配
  ↓ 注入剪辑、时间模块指令
  
STAGE-7: 故事板
  ↓ 注入剪辑模块指令
  
STAGE-8: 技能调用层（新增）
  ├─ 指数=0.2: 跳过所有模块，走原链路
  ├─ 指数=0.5: 激活5个模块，创意度L2
  └─ 指数=0.9: 激活全部14模块，创意度L5
  
STAGE-9: 运镜设计
  ↓ 注入运镜、构图、镜头语言、时间模块指令
  
STAGE-10: 渲染Prompt
  ↓ 注入灯光、色彩、氛围、空间、布景模块指令
  
STAGE-11: 后期合成
  ↓ 注入灯光、色彩、特效、质感、氛围模块指令
  
STAGE-12: 音频设计
  ↓ 注入声音模块指令
  
输出: 带创意指数影响的完整预生产
```
