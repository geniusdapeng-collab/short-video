# YUNWEI 孕味妈咪 多功能四合一宝宝座椅 — 商品档案

## 一、基础信息

| 字段 | 内容 |
|------|------|
| 品牌 | YUNWEI 孕味妈咪 |
| 产品名称 | 多功能四合一宝宝座椅 / 升级"赛车造型"洗澡座椅 |
| 产品定位 | 婴幼儿多功能护理座椅 |
| 目标人群 | 0-3岁婴幼儿家长（尤其是新手妈妈） |
| 核心场景 | 洗澡、学坐、室内移动、用餐 |

## 二、核心卖点提炼

### 🔥 卖点1：多功能四合一，一椅多用
- **洗澡椅**：360°全包围座舱，宝宝洗澡乱动也不怕
- **学坐椅**：加高设计，辅助宝宝练习坐立
- **溜溜车**：安装万向轮后化身室内"小跑车"，解放妈妈双手
- **餐椅**：可作为临时用餐座椅使用

### 🔥 卖点2：360°全包围安全座舱
- 环形护栏设计，全方位包裹防侧翻
- 宝宝洗澡时左右扭动、乱蹬腿也能稳固承托
- 从顶部视角可见完整环抱结构

### 🔥 卖点3：赛车造型工业设计
- 底座采用赛车流线型设计，视觉辨识度高
- 配色：主体白+深蓝底座+黄色护栏（经典撞色）
- 机身印有"NO.1"和"06"字样，强化运动感

### 🔥 卖点4：模块化可拆卸设计

| 模块 | 功能说明 |
|------|----------|
| 可翻转护栏 | 按压解锁，翻转后宝宝进出不卡腿 |
| 可更换把手 | 标配环形护栏，可更换为T型把手 |
| 可拆卸底座 | 底座分离后，座椅可单独放置于浴盆内 |
| 可拆卸万向轮 | 安装即变滑滑车，拆卸即固定座椅 |

### 🔥 卖点5：升级Pro全包围款
- 相比基础款，Pro款采用全包围式座舱设计
- 更适合浴盆洗澡场景，推荐浴盆使用

## 四、差异化竞争点

1. **"不只是洗澡，更是哄娃神器"** — 打破传统洗澡椅单一功能定位，延伸至娱乐、移动场景
2. **丝滑万向轮** — 强调滑行体验，将护理工具转化为"宝宝的移动乐园"
3. **按压解锁护栏** — 单手操作，解决抱娃进出不便的痛点
4. **吸盘固定** — 浴盆使用时底部吸盘防滑，双重安全保障
