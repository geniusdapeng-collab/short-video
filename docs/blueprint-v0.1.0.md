# 超短裙系统 — 极致化蓝图 v0.1.0
> 15秒短视频的暴力美学

## 一、故事浓缩器 (Story Condenser)

### 核心策略：单点极致
- **60秒故事 → 15秒浓缩**：只保留一个情绪爆点
- **3幕式压缩**：
  - 第1幕（0-3秒）：钩子 — 视觉冲击/悬念/反常识
  - 第2幕（3-10秒）：展开 — 极致细节展示
  - 第3幕（10-15秒）：收束 — 情绪升华/记忆锚点

### 和老系统的区别
- 老系统：完整的起承转合，5-8个镜头
- 超短裙：单点爆破，3-5个镜头，每个镜头都是高潮

---

## 二、镜头极致化 (Shot Perfection)

### 核心策略：少即是多
- **3-5个镜头** max，每个镜头必须 Wallpaper 级别
- **镜头类型**：
  - 开场：Extreme Close-up 或 Extreme Wide（反差制造冲击力）
  - 中段：Macro + Dynamic Movement（细节暴力美学）
  - 收束：Slow Push + Emotional Lock（情绪锁定）

### 新增能力
- **镜头密度分析**：每秒运镜变化 ≥ 2次
- **构图黄金法则**：15秒内必须有至少3种构图变化（对称/三分/引导线）
- **景深武器化**：浅景深聚焦主角，深景深展示环境压迫感

---

## 三、运镜暴力美学 (Camera Movement Brutalism)

### 核心策略：让运镜成为叙事本身
- **禁止静态镜头**：每个镜头必须有运镜（哪怕是微动）
- **运镜组合策略**：
  - 开场：Fast Orbit → 制造眩晕感/沉浸感
  - 中段：Macro Push + Tilt → 细节+情绪双杀
  - 高潮：Whiplash Pan → 视觉震撼
  - 收束：Slow Float → 情绪沉淀

### 新增运镜组合（短视频专用）
| 组合名 | 运镜序列 | 情绪效果 | 适用场景 |
|--------|----------|----------|----------|
| `hook_blast` | Fast Zoom In + Whip Pan | 炸裂/冲击 | 开场钩子 |
| `detail_porn` | Macro Push + Micro Orbit + Tilt | 痴迷/沉浸 | 产品/细节展示 |
| `emotion_lock` | Slow Push + Soft Float + Eye Lock | 共情/锁定 | 人物情绪 |
| `reveal_surge` | Low Angle + Crane Up + Wide Open | 崇高/释放 | 场景揭示 |
| `time_crush` | Speed Ramp + Slow Motion + Freeze | 时间扭曲 | 关键瞬间 |

## 四、光影雕刻 (Light Sculpting)

### 核心策略：用光影讲故事，不是照亮场景
- **3光源极简主义**：
  - Key Light：情绪色（暖=安全/希望，冷=孤独/危险）
  - Rim Light：轮廓雕刻（分离主体与背景）
  - Fill Light：微妙补光（避免死黑，保留细节）

### 新增能力
- **光影叙事矩阵**：
  - 开场：高对比 Chiaroscuro（戏剧感）
  - 中段：柔和 Rembrandt（亲密感）
  - 高潮：逆光 Silhouette（神秘感）
  - 收束：暖调 Golden Hour（希望感）
- **动态光影**：运镜过程中光影变化（模拟真实时间流逝）
- **体积光武器化**：God rays、Lens flare 作为情绪催化剂

## 五、表情微观 (Expression Microscopy)

### 核心策略：15秒不容许表情失误
- **微表情检测**：在 15fps 中捕捉 0.5秒的表情变化
- **情绪曲线**：
  - 0-3秒：好奇/惊讶（眉毛上扬，瞳孔放大）
  - 3-10秒：专注/沉浸（瞳孔锁定，嘴角微收）
  - 10-15秒：满足/震撼（嘴角微扬，眼神放光）

### 新增能力
- **表情一致性锁定**：15秒内主角表情必须情绪连贯
- **眼神追踪**：必须看向特定方向（产品/远方/镜头）
- **肌肉细节**：面部肌肉紧绷/放松的微妙变化

---

## 六、台词核弹 (Dialogue Nuke)

### 核心策略：一句话炸穿屏幕
- **15秒 = 最多3句话**（每句3-5秒）
- **台词密度公式**：
  - 中文：3-5字/秒（15秒 = 45-75字 = 3-5句）
  - 英文：2-3词/秒
- **每句必须有钩子**：悬念/反常识/情感冲击

### 新增能力
- **台词-运镜绑定**：
  - 台词高潮 → 运镜同步推向特写
  - 台词停顿 → 运镜悬浮等待
- **字幕暴力美学**：文字本身成为视觉元素（入场动画、排版设计）
- **语气词武器化**："啊"、"哇"、"嘶"作为情绪放大器

---

## 七、质感渲染 (Texture Rendering)

### 核心策略：每一帧都是壁纸
- **超写实纹理**：皮肤毛孔、布料纤维、金属划痕
- **电影级调色**：
  - Teal & Orange（冷暖对比）
  - 去饱和 + 高对比（情绪压抑）
  - 高饱和 + 柔光（梦幻感）
- **噪点控制**：胶片颗粒感（增加质感，不是降低质量）

### 新增能力
- **材质特写**：镜头必须捕捉到材质纹理
- **反射利用**：利用环境反射增加画面层次
- **粒子效果**：尘埃、光斑、水雾作为氛围填充

## 八、超短裙专属引擎 (新增模块)

### 1. 短视频节拍器 (Short Beat Engine)
- 输入：音乐/情绪/意图
- 输出：15秒节拍点（每个节拍对应一个运镜/光影/表情变化）
- 机制：BPM 分析 → 关键帧标记 → 自动绑定运镜

### 2. 钩子生成器 (Hook Generator)
- 输入：主题/产品/情绪
- 输出：前3秒最优钩子方案（视觉/听觉/叙事）
- 机制：反常识检测 + 悬念制造 + 视觉冲击

### 3. 情绪密度优化器 (Emotion Density Optimizer)
- 输入：15秒脚本
- 输出：情绪曲线优化建议
- 机制：确保情绪在15秒内有起伏（不能平铺直叙）

### 4. 短视频质检门 (Short Quality Gate)
- 更严格的评分标准（老系统70分及格，超短裙80分及格）
- 新增维度：
  - 钩子强度（前3秒是否抓住人）
  - 节奏紧凑度（有无废帧）
  - 情绪爆发力（高潮是否足够）
