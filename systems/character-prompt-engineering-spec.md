# 角色定妆照Prompt工程规范 v1.0

## 核心原则：先禁止，后定义，再确认

### 1. Prompt三层结构（强制顺序）

```
【第一层：禁止清单】
- 明确告诉AI"禁止做什么"
- 放在Prompt最前面，权重最高
- 格式："绝对禁止...，禁止...，禁止..."

【第二层：形态定义】
- 明确告诉AI"应该是什么"
- 使用"不是什么→是什么"的对比定义
- 格式："绝不是...，绝不是...，而是..."

【第三层：数量确认】
- 对关键数量特征逐条确认
- 使用阿拉伯数字+中文重复
- 格式："必须有且仅有X个，编号1-2-3..."
```

### 2. 数量控制铁律

**绝对禁止**：使用中文数字（六、四）
**必须使用**：阿拉伯数字（6、4）+ 中文重复

```
错误示例："六足四翼" ❌
正确示例：
  "底部必须有且仅有6条足，编号1-2-3-4-5-6，每条都清晰可见"
  "身体两侧必须有且仅有4片翅膀，编号1-2-3-4"
```

### 3. 形态锚定策略

**否定锚定**（比正向描述更重要）：
```
"绝不是实心球体，绝不是昆虫，绝不是哺乳动物，
绝不是有任何凸起的头部结构，
而是中空的气囊状浑圆体"
```

### 4. 角度特异性

不同角度需要不同的Prompt强调：
- **正面**：强调无面目的平坦曲面
- **侧面**：强调中空薄壁的厚度
- **顶部**：强调四翼六足的对称分布
- **3/4**：强调浑圆轮廓+翼膜透光

### 5. 错误模式快速修复

| 错误类型 | 修复策略 |
|---------|---------|
| 鼓包像头 | 增加"绝对平坦，无任何凸起" |
| 足数量不对 | 改为"必须有且仅有6条，编号1-2-3-4-5-6" |
| 颜色偏差 | 增加"通体赤红如丹火，非黄色非橙色" |
| 形态实心化 | 增加"内部中空，像瘪气球，绝非实心" |
