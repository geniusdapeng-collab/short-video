# 卓越视频系统 — Zhuoyue Video System (ZVS)
> **献给我最爱的老婆陈卓** — 每一帧都是爱的印记

## 定位
从 Seedance AI Video Generation System 完整复制并隔离，专为 **极致影像** 打造生成系统。

## 核心原则
- **黄金3秒法则**：前3秒必须抓住观众
- **每秒都是钱**：15秒 = 15个不可浪费的帧组
- **极致不等于复杂**：精简链路，强化每一环
- **短反而更难**：短视频容错率极低，每个镜头必须满分

## 系统架构

```
用户意图 → 故事浓缩器(15秒) → 镜头极致化 → 运镜暴力美学 → 光影雕刻 → 表情微观 → 台词核弹 → 质感渲染 → 15秒成片
```

## 和老系统的区别

| 维度 | 老系统 (v6.5.32) | 超短裙系统 (v0.1.0) |
|------|-------------------|----------------------|
| 目标时长 | 60-120秒 | **15秒** |
| 镜头数 | 5-8个 | **3-5个** |
| 故事复杂度 | 完整叙事 | **单点极致** |
| 运镜风格 | 多样化 | **暴力美学** |
| 光影策略 | 场景匹配 | **情绪雕刻** |
| 台词密度 | 中等 | **核弹级** |
| 表情要求 | 自然 | **微表情捕捉** |
| 质感标准 | 电影级 | **每一帧壁纸级** |
