## 🔴 队长反馈驱动

**问题**: "优化的是这一个case，不是系统机制。第二个主题来了，同样的问题会复发。"

**根因**: v4.4之前，时长分配和过渡设计都是**手动/外部脚本**，没有集成到主链路。

**解决方案**: 把两个新模块**硬编码进build-storyboard主链路**，任何主题自动经过这些环节。

## 🛠️ 系统集成详情

### 新增STEP 3.5: 语义完整性校验 + 弹性时长分配

**位置**: `scripts/build-storyboard-v4.1.js` 第612行（STEP 3之后，STEP 4之前）

**模块**: `systems/semantic-integrity-validator.js`

**功能**:
- 不同内容类型动态语速：开场4.0/讲解4.2/互动5.0/警示3.5字/秒
- 语义缓冲：医学术语+1秒/数字对比+1.5秒/三个要点+1秒/警示语+1秒
- 弹性区间：targetDuration ±30%（默认59秒→41-77秒）
- 完整性规则：完整句子不截断/医学术语需慢说/数字对比需停顿/三个要点需展开/警示语需强调
- 自动修正：推荐时长在弹性区间内→采用推荐；超出上限→按比例压缩；低于下限→按最低值

**输入**: allocator分配的时长 + narration内容 + 镜头类型
**输出**: 修正后的时长（已写入scene.duration）

### 新增STEP 4.5: 过渡衔接设计

**位置**: `scripts/build-storyboard-v4.1.js` 第700行（STEP 4之后，STEP 5之前）

**模块**: `systems/transition-designer.js`

**功能**:
- 验证故事板连贯性（检测逻辑断层）
- 自动添加过渡镜头（当检测到断层时）
- 过渡台词模板：symptoms-to-treatment / check-to-summary / cause-to-symptoms / opening-to-topic / summary-to-closing
- 断层检测：因果链完整性/角色转换缓冲/总结突兀检查

**输入**: 基础故事板（不含过渡）
**输出**: 含过渡镜头的完整故事板（自动保存到storyboard.json）

## 📝 经验教训

1. **case级优化 ≠ 系统级优化**: 修改一个主题的内容是case级，集成到主链路才是系统级
2. **新模块必须进主链路**: 外部脚本/独立文件不算系统级，必须集成到标准流程
3. **弹性区间优于硬编码**: 59±30%比固定59秒更实用
4. **语义完整性是独立系统**: 不应和时长分配耦合，单独做validator
