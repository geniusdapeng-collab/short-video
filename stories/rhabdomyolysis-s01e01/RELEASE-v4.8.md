## 🎯 核心变更

### 1. 后期合成固定制度 v1.0（首次固化为系统级规则）

**职责分离原则：**
| 环节 | 负责内容 | 禁止事项 |
|------|----------|----------|
| 视频生成API | 画面 + 口型动作 | ❌ 严禁依赖API自带音频 |
| TTS配音 | 说话内容 + 音频时长 | ❌ 严禁TTS音频超过视频时长 |
| 后期合成 | 音画同步 + 拼接 | ❌ 严禁保留API原声 |

**音色分配（固定）：**
| 角色 | 音色 | voice ID | 适用场景 |
|------|------|----------|----------|
| 小陈/陈女士 | 女声 | zh-CN-XiaoxiaoNeural | 通用型视频主持人 |
| 小G | 童声 | zh-CN-XiaoyiNeural | 通用型视频互动角色 |
| 其他角色 | 按角色档案voice字段 | 动态匹配 | 按档案配置 |

**分辨率标准：**
- 目标：1920x1080 (16:9)
- 当前：1280x720（Seedance 2.0输出，下版升级）

**输出规范：**
- ✅ TTS音频覆盖（无API原声残留）
- ✅ 精确时长匹配（TTS ≤ 视频时长）
- ❌ 不烧录字幕（除非队长特别要求）

### 2. 山海经系列特殊规则

| 项目类型 | 音频方案 | 字幕 | TTS |
|----------|----------|------|-----|
| 通用型（科普/纪录片） | TTS覆盖 | 按需 | ✅ |
| 山海经系列（Nirath） | 原声保留 | ❌ | ❌ |

**山海经规则：**
- ✅ 直接拼接原视频片段
- ✅ 保留原始视频自带的声音和音效
- ❌ 不添加TTS配音
- ❌ 不烧录字幕
- ❌ 不做任何音频处理

## 🛠️ 技术实现

```bash
# 1. 生成TTS音频
edge-tts --voice zh-CN-XiaoxiaoNeural --text "$narration" --write-media audio.mp3

# 2. 替换视频音频
ffmpeg -i video.mp4 -i audio.mp3 \
  -c:v copy -c:a aac \
  -map 0:v:0 -map 1:a:0 \
  -shortest output.mp4

# 3. 拼接最终视频
ffmpeg -f concat -safe 0 -i list.txt -c copy final.mp4
```

## 📝 教训记录

**AI视频生成技术的根本限制（行业共识）：**
1. Seedance 2.0 / Sora / Veo 无法控制角色说话内容
2. 模型根据视觉提示词自由生成音频，内容/时长均不可控
3. duration参数只约束视频长度，不约束音频时长
4. **唯一可靠方案**：后期TTS配音覆盖

**后续项目必须执行：**
- 通用型视频生成后必须走TTS覆盖流程
- 不再尝试让API生成正确音频内容
- TTS作为独立生产环节，与视频生成并行
