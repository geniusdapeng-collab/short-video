## 🔴 背景

v4.7七坑全填发布后，在完整链路运行时发现多个运行时问题：
1. **字数爆炸**：全字段提取导致双人镜S04字数494字，超过490字上限
2. **Action重复**：双人镜中两个角色都添加相同action描述，造成冗余
3. **边界问题**：短字段（如"28岁"）被去重逻辑误过滤
4. **时长超限**：语义校验器推荐13秒，但API限制12秒

---

## 🛠️ 修复内容

### 修复1: 字数控制分级策略
**问题**: v4.7全字段提取后，角色描述过长，双人镜超限
**修复**: 实施分级字数预算
- 主角色（单镜/双人镜中的主要角色）：90字预算
- 次要角色（双人镜中的非主要角色）：50字预算
- 字段优先级：P0声音锚点 → P1年龄/表情/嘴部 → P2表情描述 → P3发型/体型
**影响**: S04从494字降至465字（合规）

### 修复2: 双人镜Action去重
**问题**: S04中两个角色都写"正在小G提问，小陈倾听并准备回答，围绕...进行互动交流"
**修复**: 仅主角色（shot.characters[0]）添加action，次要角色只保留基础描述
**影响**: 减少冗余，节省~30字

### 修复3: 去重阈值修正
**问题**: "28岁"（2个字符+数字）被 `pClean.length > 3` 过滤
**修复**: 阈值改为 `pClean.length >= 2`
**影响**: 年龄、体型等短字段不再被误过滤

### 修复4: 体型字段兼容
**问题**: xiaoG用 `appearance.body`，chen-nurse用 `appearance.build`
**修复**: 同时检查两个字段名 `appearance.build || appearance.body`
**影响**: 所有角色的体型描述都能正确提取

### 修复5: Unknown性别推断增强
**问题**: xiaoG的 `voiceIdentity.gender` 为undefined，导致性别锚点丢失
**修复**: 当gender为undefined/unknown时，用 `baseIdentity` + `age` 推断
**影响**: xiaoG获得正确的童声锚点

### 修复6: 过渡镜头Movement修复
**问题**: `transition-designer.js` 使用 `smooth_pan`，但 `camera-movement-system.js` 不存在该动作
**修复**: 改为 `follow`（通用的跟随动作）
**影响**: 过渡镜头运镜配置有效

### 修复7: API_MAX_DURATION确认
**问题**: 语义校验器推荐13秒，超出限制
**修复**: 保持 `API_MAX_DURATION = 12`，语义推荐超限时自动clamp到12秒
**队长确认**: 队长确认12秒可用，保持当前限制

## 📝 经验教训

1. **全字段提取需要字数控制**：信息多不等于prompt好，要在490字限制内取舍
2. **分级预算策略**：主角色多字，次要角色少字，字段按优先级排序
3. **Action去重是双人镜关键**：两个角色不能重复相同动作描述
4. **边界情况要测试**："28岁"这种短字段容易被简单阈值过滤
5. **字段名兼容**：不同角色档案结构不同，要支持多种字段名
