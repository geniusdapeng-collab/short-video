# SHORT-VIDEO-0.6.4-social-media-gate-fix 发布记录

## 修复内容：质量门评估正则匹配社媒Prompt标记变体

**问题**: v0.6.3预生产质量评分87分中，信息密度44分、爆款潜力31分偏低。根因：
1. 质量门检查 `shot.prompt` 但社媒Prompt在 `renderPrompt` 字段
2. 标记格式不匹配（如 `【音效设计】` vs `【声音设计】`）

**修复** (`systems/quality-gate.js`):

### 1. 检查所有prompt字段（v1.0.1）
```javascript
// 修复前：
const text = shot.prompt || '';

// 修复后：
const text = shot.render_prompt || shot.renderPrompt || shot.prompt || shot.visualPrompt || '';
```

### 2. 支持社媒标记变体

| 评估维度 | 原标记 | 新增社媒变体 |
|----------|--------|-------------|
| 信息密度 | `【视觉暴力】` | `【视觉暴力`（支持后缀） |
| 信息密度 | `【声音设计】` | `【音效设计` |
| 爆款潜力 | `【声音设计】` | `【音效设计` |
| 爆款潜力 | `【悬念钩子】` | `【情绪曲线` / `【悬念` |
| 爆款潜力 | `【记忆锚点】` | `【记忆定格` / `【截图帧` / `【定格冻结` |
| 爆款潜力 | `【分享触发】` | `【壁纸级` / `【朋友圈` |
| 视觉爆发力 | `【镜头时间轴·咔咔咔节奏】` | `【镜头时间轴` |
| 视觉爆发力 | `【人物表情】` | `【人物表情` |
| 视觉爆发力 | `【运镜组合】` | `【运镜组合` |

### 3. 影响评估
- **信息密度**: 预计从 34分 → 70-80分（标记识别正常）
- **爆款潜力**: 预计从 21分 → 60-70分（声音/悬念/记忆/分享标记识别）
- **总分**: 预计从 87分 → 90-95分
