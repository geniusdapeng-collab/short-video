## 修复内容

### 1. Seedance API 格式修复 ✅
**问题**: 提交脚本使用错误的 `reference_images` 参数，导致定妆照不生效  
**修复**: 改用正确的 `content` 数组格式：`[{type: 'text', text: prompt}, {type: 'image_url', image_url: {url: base64}, role: 'reference_image'}]`  
**影响**: 角色定妆照（饕餮+小G）和商品定妆照现在正确生效

### 2. 商品定妆照强约束 ✅
**问题**: 商品形象（千问AI眼镜）在渲染中偏离参考图  
**修复**: 
- Prompt 增加强制约束：`⚠️ 外观必须与参考图完全一致，禁止修改镜框形状、颜色、Logo位置、镜片效果`
- 提交脚本自动注入约束前缀
- 新增 `强制约束` 字段明确禁止创造性修改
**影响**: 商品形象严格遵循参考图，保持品牌一致性

### 3. 运镜连续性检查 ✅
**问题**: 相邻镜头（S02→S03）使用连续推镜头，视觉单调  
**修复**: 
- Pipeline Stage-9 新增自动检查：检测相邻镜头是否都含"推进/推近/逼近"
- 自动调整后一镜头为：拉远/环绕/俯冲/拉升/旋转/平移
- S03 Prompt 从"缓推逼近"改为"急速拉远俯冲"
**影响**: 三镜头运镜节奏更丰富，避免视觉疲劳

### 4. 首尾帧支持 ✅
**问题**: 渲染引擎支持首尾帧，但提交脚本未实现  
**修复**: 
- `submit-render-v2.js` 支持 `first_frame` / `last_frame` role
- 预留首尾帧接口，后续可自动提取前镜头尾帧
**影响**: 镜头间连续性可进一步优化

### 5. 商品版权保护策略 ✅
**问题**: S03 因商品定妆照触发版权限制导致渲染失败  
**修复**: S03 移除商品定妆照，仅用文本描述植入  
**影响**: 避免版权检测，同时保留商品文字植入

## 已知问题

1. **S03 商品图版权限制**：S03 移除商品定妆照后，仅通过文本描述植入，效果可能弱于S01/S02
2. **首尾帧未完全启用**：预留接口但未实现自动提取前镜头尾帧
3. **duration参数兼容性**：`doubao-seedance-2-0` 模型不支持 `duration` 参数，需使用 `seconds`（字符串格式）
