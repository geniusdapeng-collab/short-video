## 教训

1. **看规范文件比看输入文件更重要**：`beast-domain-model.js` 定义了 canonical ID `taotie`，输入文件中的 `tao-tie` 只是兼容别名，不应反向修改系统去匹配别名。
2. **源头修复优于下游补丁**：StoryCraft 的 `visualPrompt 30-80字` 限制是根因，下游 buildPromptV3 再怎么升级回收也救不回来。修复上游 LLM Prompt 要求是最有效的方式。
3. **执行顺序影响数据完整性**：Stage 7.3 在 7.4 之前执行导致 narration 被截断后无法恢复，交换顺序即可解决。
