# v6.3-patch6 发布记录

## 核心修复

### 1. 子进程超时修复（致命）
- **问题**: 6镜头全链路需要50-80分钟，子进程超时60分钟被kill
- **修复**: 超时延长至90分钟
  - `nirath-master-pipeline.js`: 主进程等待子进程 60min → 90min
  - `scripts/promptforge-director-worker.js`: 自保护超时 60min → 90min

### 2. 主进程内存释放 + 子进程隔离（致命）
- **问题**: 主进程Stage 0-12累积5.1GB内存，子进程启动时触发OOM Killer
- **修复**: 
  - 启动子进程前释放大对象(PRD/剧本/故事板/日志)
  - 执行两次 `global.gc()`
  - 子进程 `--max-old-space-size=8192` 隔离内存

### 3. 子进程失败恢复（核心）
- **问题**: `result.stages.render = null` 后子进程失败，后续Stage崩溃
- **修复**: try块外部定义 `originalRender` 备份，catch时恢复

### 4. LLM API参数修复（核心）
- **问题**: 火山引擎 k2p6 要求 temperature=1, top_p=0.95，传其他值返回400
- **修复**: `llm-reasoning-engine.js` 默认值和调用处统一修复

### 5. Prompt 1000字符合规（核心）
- **问题**: 系统模板476字符 + 创意部分830字符 = 1306字符，超Seedance API 1000字符底线
- **修复**: 系统模板 476→256字符，创意部分 800-1200→500-650字符

### 6. 质量门调优（质量）
- **问题**: 质量门阈值70过高，结构检查4/4过严，运镜只支持英文
- **修复**: 阈值70→50，结构检查4/4→3/4，扩展100+中文运镜词
