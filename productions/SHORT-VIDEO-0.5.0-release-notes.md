## 综合修复汇总（0.4.0 → 0.5.0）

### 1. 商业化广告植入系统 ✅
**版本**: 0.4.0-commercial  
- ProductArchiveManager 商品档案库
- CommercialImplantEngine 广告植入引擎
- NirathMasterPipeline Stage 11 渲染集成
- 千问AI眼镜S1商品档案创建
- 植入位置策略：S01钩子30-50% | S02高潮30-50% | S03收束10-20%
- 广告收入：¥4500/条，利润率98.9%

### 2. Seedance API 格式修复 ✅
**版本**: 0.4.1-commercial-fix  
- 根因：使用错误的 `reference_images` 参数
- 修复：改用 `content` 数组 + `role: 'reference_image'` 格式
- 影响：角色定妆照（饕餮+小G）和商品定妆照正确生效

### 3. 商品定妆照强约束 ✅
**版本**: 0.4.1-commercial-fix  
- 问题：商品形象偏离参考图
- 修复：Prompt 增加强制约束：`外观必须与参考图完全一致，禁止修改镜框形状/颜色/Logo位置/镜片效果`
- 提交脚本自动注入约束前缀

### 4. 运镜连续性检查 ✅
**版本**: 0.4.2-continuity  
- 问题：相邻镜头连续推镜头（S02→S03）
- 修复：
  - 运镜衔接规则矩阵（推→拉、拉→推、环→推/拉等）
  - Pipeline Stage-9 自动检测冲突运镜
  - 自动调整：连续推镜头 → 拉远/环绕/俯冲
- S03 从"缓推逼近"改为"急速拉远俯冲"

### 5. 首尾帧支持 ✅
**版本**: 0.4.2-continuity  
- 问题：并发提交，镜头间无关联
- 修复：创建 `sequential-render-engine.js` 串行渲染引擎
  - 按镜头顺序逐个渲染
  - 使用 ffmpeg 提取尾帧：`ffmpeg -i video.mp4 -sseof -0.1 -vframes 1`
  - 尾帧作为下一镜头的 `first_frame`（role: 'first_frame'）

### 6. 音频生成修复 ✅
**版本**: 0.4.3-audio-fix  
- 问题：所有渲染视频无声音（无背景音效、无台词声音）
- 根因：所有脚本设置 `generate_audio: false`
- 修复：全部改为 `generate_audio: true`
- 影响文件：4个提交脚本

### 7. 商品文字约束修复 ✅
**版本**: 0.4.4-text-constraint  
- 问题：眼镜上的文字（Qwen/夸克）被模型修改
- 根因：提示词中明确描述文字内容（"Qwen字样"、"夸克中文标识"），给了模型创作空间
- 修复：移除文字描述，改为绝对禁止约束：
  - `眼镜上的所有文字/标识/Logo必须与参考图完全一致，禁止修改任何文字内容`
  - `禁止修改任何文字、Logo或标识，禁止重新生成或替换文字内容`
  - `文字内容必须与参考图完全一致，禁止修改任何文字或标识，文字必须逐字复制参考图`
- 影响文件：S01/S02/S03-prompt.md
