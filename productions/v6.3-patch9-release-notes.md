## 修复内容

### 🔥 关键修复：`_cleanForgePrompt` 正则 Bug

**问题**: `metaPrefixMatch` 正则 `/^(.*?)([\u4e00-\u9fa5a-zA-Z].*)/` 中的 `.*` 不匹配换行符，导致多行 Prompt 被截断为3字符

**影响**: 全链路预生产中，PromptForge 子进程返回的质量分90分 Prompt 被截断为3字符，导致 Stage 13 链路中断

**修复**: 删除危险的 `metaPrefixMatch` 正则逻辑，只清理字符计数残留，不删除任何内容

**验证**:
- 修复前：594 字符 → 3 字符（错误）
- 修复后：594 字符 → 588 字符（正确，仅清理6个字符计数残留）

## 根因

```javascript
// 错误代码（v6.3-patch8）
const metaPrefixMatch = cleaned.match(/^(.*?)([\u4e00-\u9fa5a-zA-Z].*)/);
// .* 不匹配换行符，导致 "【视觉】\n异兽..." 只匹配到 "视觉】"（3字符）

// 修复后（v6.3-patch9）
// 删除该正则，只清理字符计数残留
```
